A program for simulating Blokus games with different strategies quickly (WIP)

Für W-Seminar Mathematik/Spieltheorie

# Build instructions

1. Install Rust (see https://rustup.rs/) and git (see https://git-scm.com/install/)
2. Open a terminal and navigate to a directory where you want to clone the repository
3. Clone this repository (`git clone https://github.com/DerCommander323/blokus-sim.git`)
4. Run `cargo run --release`
